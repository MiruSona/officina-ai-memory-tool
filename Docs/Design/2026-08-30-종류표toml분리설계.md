# 기억 종류 표를 vocab.toml 로 빼기 · 새 종류 `fact`

## 1. 결론

기억 종류마다 다른 취급을 **표 한 장(`model.TypeSpec`)**으로 모으고, 그 표를
`Memory/vocab.toml` 의 `[type.<이름>]` 절로 덮어쓸 수 있게 한다. 지금은 이 취급이
`validate.go` · `quality/` 5파일 · `search/score.go` · `gc/plan.go` · `index/hook_queries.go`
여덟 군데에 흩어져 있다.

- **표로 뺄 수 있는 것** : 필수 칸(sources·severity·todo_status), 본문 꼴, 낡음 일수,
  검색 반감기·가산, gc 접기 면제, 훅 절 이름, 값 검사 on/off, 「한 건 하나」, 결정 관문 on/off.
- **코드에 남는 것** : 검사의 *내용*(issue 절 이름과 2줄 조건, howto 번호 판정, 관문 임계값,
  반감기 수, gc 의 caution·todo 추가 조건). toml 은 **이름으로 고를 뿐** 새 로직을 못 만든다.
- **toml 이 없거나 절이 비면 코드 안 기본표(7종)로 돈다.** 다른 프로젝트에 깔아도 그냥 돈다.
- 새 종류 **`fact`**(환경 사실)를 기본표에 넣는다.

## 2. toml 규격

```toml
[type.fact]
label        = "환경 사실"   # 도움말·오류 문구에 쓰는 이름 (새 종류는 필수)
sources      = "required"    # required | warn | none        기본 none
severity     = false         # true 면 필수, 아니면 붙이면 거절  기본 false
todo_status  = false         # 위와 같다                        기본 false
body         = "free"        # free | issue-sections | numbered  기본 free
evidence     = false         # 본문에 확인 가능한 조각 요구      기본 false
conclusion   = false         # 결론 문장 요구                    기본 false
one_thing    = true          # 한 건에 하나. true=거절, false=경고  기본 false
gate         = false         # 저장 전 충돌 관문(C04)            기본 false
stale_days   = 360           # 낡음 후보 일수. 0 = 안 봄         기본 0
half_life    = "none"        # none | history(90일) | decision(720일)  기본 none
gc_keep      = true          # 본문 접기 면제                    기본 false
search_bonus = false         # 검색 가산 +0.3                    기본 false
hook         = "환경"        # 세션 훅 절 이름. 비우면 안 실림   기본 ""
```

### 기본표 (= 지금 동작 그대로 + fact)

| type | label | sources | sev | todo_st | body | evi | conc | one | gate | stale | half | gc_keep | bonus | hook |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| todo | 할 일 | none | ✗ | **필수** | free | ✗ | ✗ | ✗ | ✗ | 0 | none¹ | ✗¹ | ✗ | 열린 이슈·할 일 |
| history | 기록 | **warn** | ✗ | ✗ | free | ✓ | ✗ | ✗ | ✗ | 180 | history | ✗ | ✗ | — |
| issue | 이슈 | required | **필수** | ✗ | issue-sections | ✓ | ✗ | ✗ | ✗ | 0 | none | ✓ | ✓ | 열린 이슈·할 일 |
| caution | 주의 | required | **필수** | ✗ | free | ✗ | ✗ | ✗ | ✗ | 0 | none | ✓ | ✗ | 열린 이슈·할 일 |
| decision | 결정 | required | ✗ | ✗ | free | ✓ | ✓ | ✓ | ✓ | 1440 | decision | ✓ | ✓ | 최근 결정 |
| howto | 하는 법 | none | ✗ | ✗ | numbered | ✓ | ✗ | ✗ | ✗ | 1440 | decision | ✓ | ✗ | — |
| **fact** | **환경 사실** | **required** | ✗ | ✗ | free | ✗ | ✗ | **✓** | ✗ | **360** | none | **✓** | ✗ | **환경** |

¹ todo 는 `todo_status=done` 이면 반감기가 history 로 바뀌고 gc 접기 대상이 된다. 열린 todo 는 면제다.
이 조건부는 표 한 칸으로 못 적어 `gc_keep`·`half_life` 코드 쪽에 `done` 예외를 그대로 둔다 (5절).

훅 절 차례는 `고정 · 최근 결정 · 열린 이슈·할 일 · 환경 · 알림` 이다. toml 이 만든 새 절 이름은
`환경` 뒤, `알림` 앞에 toml 에 적힌 차례대로 붙는다. 절마다 최근 5줄, 블록 8000바이트 상한은 그대로다.

## 3. 코드 구조

- `internal/model/typespec.go` (새 파일)
  - `type TypeSpec struct { Name, Label, Sources, Body, HalfLife, Hook string; Severity, TodoStatus, Evidence, Conclusion, OneThing, Gate, GCKeep, SearchBonus bool; StaleDays int }`
  - `type TypeTable []TypeSpec` + `func (t TypeTable) Get(name string) (TypeSpec, bool)` · `Names() []string`
  - `func DefaultTypes() TypeTable` — 위 기본표 7종. `var Types` 는 `DefaultTypes().Names()` 로 남긴다 (호출부 유지).
  - `TypeFact = "fact"` 상수 추가.
  - **`model` 은 `config` 를 못 가져온다** (`config` 가 `model` 을 가져오니 순환). 그래서 기본표는 `model` 에 두고 toml 파싱은 `config` 가 한다.
- `internal/config/vocab.go`
  - `Vocab` 에 `Types model.TypeTable` 칸을 더한다. `DefaultVocab()` 은 `model.DefaultTypes()`.
  - `ParseVocab` 이 `[type.*]` 절을 읽어 **이름별·칸별 덮어쓰기**로 병합한다 — toml 에 적힌 이름의, 적힌 칸만 바꾼다. 안 적은 종류·안 적은 칸은 기본값 그대로다. **기본 7종은 toml 로 못 지운다** (지우면 이미 저장된 기억이 통째로 규격 밖이 된다).
  - 모르는 칸 이름 → **경고 한 줄 찍고 무시**(옛 mem 이 새 toml 을 읽어도 돌아야 한다). 모르는 값(`body = "표"`) → 경고 + 그 칸만 기본값. 종류 이름 규격은 scope 와 같이 `^[a-z][a-z0-9-]{1,19}$`, 어기면 그 절을 통째로 버린다.
  - `EncodeVocab` 이 `[type.*]` 를 주석과 함께 쓴다. `vocabSections` 에는 **안 넣는다** — 넣으면 이미 있는 저장소가 전부 `init --check` 에서 「빠진 절」로 잡힌다 (9절 판단거리).
- 배선 : `quality.Options` 는 이미 `Vocab` 을 들고 있어 `opt.Vocab.Types` 로 바로 닿는다. `search.Options` 에 `Types model.TypeTable` 칸을 더한다(0값이면 `model.DefaultTypes()`). `index`·`gc` 는 이미 `config` 를 가져오므로 `HookPick`·`gc.Plan` 에 표를 넘긴다.
- `model.Validate` 는 표를 못 받는다 (인자 없는 함수, 호출부 8곳). **`ValidateWith(m, spec, table)` 를 새로 만들고 `Validate`/`ValidateAs` 는 `DefaultTypes()` 로 부르는 얇은 껍데기로 둔다.** `index/promote.go`·`indexer.go` 의 승격 검사만 `ValidateWith` 로 바꾼다 (거기는 저장소 설정을 이미 들고 있다).
- **`mem tags --add-type` 은 안 만든다.** 종류는 태그와 달리 거의 안 늘고, 잘못 넣으면 저장소 전체가 규격 밖이 된다. 사람이 `vocab.toml` 을 직접 손보게 두고, 대신 `mem tags --check` 가 「표에 없는 type 을 쓴 기억 N건」을 세어 준다.

## 5. 못 빼는 것과 까닭

- **issue 절 검사 내용** (`## 증상`·`## 해결`, 각 2줄) — 절 이름이 한국어 규칙이라 toml 로 열면 검사가 아니라 새 언어가 된다. `body = "issue-sections"` 로 **고르기만** 한다.
- **howto 번호 판정** (`1.` `2.` 두 단계, ①② 제외) — 위와 같다.
- **결정 관문 임계** (태그 겹침 2 · 요약 닮음 0.025) — 실기억 126짝 분포로 잡은 값이다. 표에는 on/off 만 둔다.
- **반감기 수 90·720** — 이름으로만 고른다. 임의 수를 열면 검증 안 된 감쇠가 돌고, 낡음 일수(= 반감기 ×2)와 어긋난다.
- **gc 의 나머지 조건** — `todo_status<>'done'`, `caution severity=high` 면제, scope 당 최근 caution 30건, links·importance·last_hit. 표 한 칸으로 안 되는 SQL 조건이라 그대로 둔다.
- **severity·todo_status 값 목록** (high·mid·low / open·doing·done) — 값 자체는 코드. 표는 「쓰나 안 쓰나」만 정한다.
- **훅 줄 표식과 절 정렬** (`[고정]`·`[할일]`·`[높음]`) — 코드.

## 9. 판단이 필요한 것

1. `model.Validate` 에 표를 넘기는 길 — `ValidateWith` 신설(추천) vs `model.SetTypes()` 전역 1회 설정(간단하지만 시험 격리가 깨진다).
2. `vocabSections` 에 `type` 을 넣나 — 넣으면 기존 저장소가 전부 `mem init --check` 에서 「빠진 절」로 잡힌다. 안 넣기를 추천.
3. `gate`·`one_thing` 을 정말 표 칸으로 열 것인가 — 임계값이 decision 실측으로만 잡혀 있어, 다른 종류가 켜면 검증 안 된 관문이 돈다. on/off 만 열고 기본은 decision 만 켠다로 잡았다.
4. 훅에 절이 하나 늘면 8000바이트를 다섯 절이 나눠 먹는다. 절당 5줄을 그대로 둘지, `환경` 만 3줄로 할지.
5. 기본 7종을 toml 로 **끄는** 길(`hidden`)을 둘지 — 이번엔 안 둔다로 잡았다.
