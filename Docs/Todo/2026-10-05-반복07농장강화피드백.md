# 반복 07 농장 강화 피드백 (ProjectMozzi)

> 2026-10-05 · 게임 저장소 `ProjectMozzi2` 반복 07 코드 갈래(서브에이전트)에서 `mem search` · `show` · `add` · `set --done` 을 쓴 기록.

## 막힌 것

- `--sources "note:반복 07 Play 확인 …,file:…"` 처럼 note 값에 빈칸이 있으면 따옴표 없이 줄 때 「옵션 값이 아닌 낱말」 로 거절된다. 메시지는 맞지만
  note: 는 사람 말이라 빈칸이 흔하다. 오류 문구에 「빈칸이 든 값은 통째로 따옴표로 감싼다」 한 줄이 있으면 한 번에 맞힌다.
- 할 일 닫기를 `mem todo <id>` 로 찾았다가 없는 명령이었다. `mem set <id> --done` 이 맞다. `mem help` 첫 화면에 「할 일 닫기 → set --done」 이 보이면 좋다.

## 잘 된 것

- 시작 훅 요약과 `mem show` 로 이번 결정 · 할 일을 바로 읽고 일을 시작했다. `set --done` 뒤 `mem index` 로 곧바로 반영됐다.

## 반복 07 주방 배선 (같은 날 · 코드 갈래 둘째 판)

- 막힌 것 : caution 을 `--severity` 없이 넣다가 「거절됨 — 1가지」 만 나오고 까닭이 안 보였다. `--check` 를 붙여서야 「severity 가 있어야 한다」 를 봤다. 거절 때 까닭 한 줄을 바로 찍어 주면 한 번에 고친다.
- 잘 된 것 : `--check` 가 닮은 기억 · 요약-본문 어긋남까지 미리 알려 줘 본문 첫 줄을 결론으로 고쳐 넣었다.
