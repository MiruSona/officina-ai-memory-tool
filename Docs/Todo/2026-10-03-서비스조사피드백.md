# 2026-10-03 서비스 코드 조사 갈래 피드백

조사 문서 하나를 쓰고 `mem add --type fact` 한 건을 남기며 본 것.

## 막힌 것

- `--type fact` 가 **본문(`--body`) 3줄 이상**을 요구하는데, 게임 저장소의 `mem-usage` 스킬에는 「title · summary · tags · scope 늘 필요 + sources」만 적혀 있어 처음 두 번 거절됐다.
  → `mem add` 거절 메시지에 「`--body` 로 3줄 이상」 예시 한 줄이 있으면 한 번에 통과한다.
- 첫 거절은 10가지가 한꺼번에 나왔는데, 태그 안내(`mem tags --list`) 넉 줄이 앞을 차지해 정작 거절 까닭이 `tail` 에서 잘렸다. 거절 까닭을 먼저, 안내를 뒤에 두면 좋겠다.

## 잘 된 것

- 표준 태그 제안(`mem tags --add vfx`)이 바로 나와 어떤 태그를 써야 하는지 금방 알았다.
- `mem search 컷씬 스토리` 가 0건일 때 「저장소에 그 낱말이 없다」를 분명히 말해 줘 헛된 재시도를 안 했다.
