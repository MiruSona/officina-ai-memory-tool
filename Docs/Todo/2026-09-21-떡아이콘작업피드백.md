# 떡 아이콘 작업에서 쓴 피드백 (2026-09-21)

떡 아이콘 11장을 그리고 배선한 판에서 `mem` 을 쓰며 본 것이다.
앞 문서(`2026-09-20-재료아이콘작업피드백.md` 등)에 이어 쓴다. 거기 적힌 것은 다시 풀지 않는다.

## 결론

- **`decision-gate` 가 안 부딪히는 결정을 막았다.** 떡 아이콘 확정을 `decision` 으로 넣으려다
  같은 scope(`art`)의 살아 있는 결정 둘(`20260920-11b31f30` 재료 아이콘 · `20260921-08cf47a7` 건물 그림)과
  「부딪힌다」고 거절됐다. 셋은 서로 다른 그림 갈래라 뒤집을 것이 없다. 결국 `history` 로 넣었다.
- 거절 메시지가 주는 다음 수는 **`--by <옛id>` 로 덮기**와 **주제 바꾸기** 둘뿐이다.
  「안 부딪힌다」고 말할 길이 없다.

## 막힌 것

| # | 무엇 | 어떻게 됐나 | 바라는 것 |
| --- | --- | --- | --- |
| 1 | `decision-gate` 오탐 | 아트 결정은 태그가 늘 `art` + `ui` 라 **태그 겹침 2 조건이 언제나 참**이다. 남는 관문은 요약 닮음뿐인데 `gateSummaryCut = 0.025`(`internal/quality/gate.go`)가 매우 낮아, 「아이콘」 「그림」 같은 흔한 낱말 몇 개만 겹쳐도 걸린다 | ① 태그 겹침을 셀 때 `art` 처럼 scope 와 뜻이 겹치는 상위 태그는 빼고 센다 ② 또는 `--not-rival <id>` 처럼 **안 부딪힌다고 말하는 길**을 준다 |
| 2 | 다음 수에 「그냥 넣기」가 없다 | 안내가 `--by` 로 덮기와 주제 바꾸기 둘이다. 결정을 살리려면 멀쩡한 남의 결정을 덮어야 한다 — 위험한 길이 가장 쉬운 길이 됐다 | 「정말 다른 주제면 `--new`」 를 안내 줄에 같이 찍는다 (`--new` 가 이 관문을 지나는지도 도움말에 적어 준다) |
| 3 | 다시 못 냈다 | 같은 내용을 말만 바꿔 `--check` 로 돌리니 **관문을 다 지났다.** 막느냐 마느냐가 요약 낱말 몇 개에 달려 있어, 같은 일을 두 사람이 남기면 한쪽만 막힌다 | 거절할 때 **닮음 점수와 겹친 태그를 같이 찍는다.** 왜 막혔는지 알아야 고치거나 넘길 수 있다 |

## 잘 된 것

- `mem set <옛id> --by <새id>` 로 낡은 `fact` 덮기가 한 줄에 끝났다. 덮은 뒤
  「이 기억을 근거로 삼은 기억이 몇 건인지」까지 알려 준다.
- `mem add --check` 가 있어 관문에 걸릴지 미리 보고 넣을 수 있었다.
- `history` 관문은 본문 「왜 · 무엇을 · 다음에」 3줄을 요구해서, 공수 눈금을 남길 때
  까닭과 다음 눈금을 같이 적게 된다. 나중에 읽기 좋다.
