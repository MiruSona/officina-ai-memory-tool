```powershell
# 3번 시험 — transcript_path 는 파일 고침이 5번 넘는 아무 세션 기록
'{"hook_event_name":"Stop","session_id":"0000aaaa-0000-0000-0000-000000000000","cwd":"<저장소 뿌리>","transcript_path":"<기록.jsonl>"}' | mem hook stop --dry-run
```

**끄기** — 둘 중 하나.

- 잠깐 끄기 : `Memory/mem.toml` 의 `[retain]` 에서 `nudge = false` (훅은 붙어 있어도 침묵한다).
- 떼기 : `mem init --retain --undo` (자동 쌓기 훅 셋만 걷는다. `SessionStart`·`SubagentStart` 는 그대로).

**들어온 것이 이상하면** — `mem auto list` 로 보고 `mem auto undo --origin stop --since <날짜>` 로 미리보기 → `--apply`.
되살리기는 `mem auto redo --apply`. 하나씩 버리기는 `mem review --reject <id>`.
