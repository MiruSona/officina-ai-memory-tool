# 표준 태그 목록을 볼 길이 없다 (2026-09-21)

게임 저장소에서 UI 고침 두 건을 `mem add` 로 남기다가 두 번 거절당했다.

## 막힌 것

1. `--tags "art,code,ui"` 로 넣으니 **`code` 는 표준 태그 목록 밖**이라며 거절됐다 (`tag-standard`).
   - 그런데 `--scope code` 는 표준 scope 다. 같은 낱말이 scope 로는 되고 태그로는 안 되니 헷갈렸다.
2. 거절 메시지는 `mem tags --add code` 를 권하는데, 그건 **표준을 늘리는** 명령이라
   이 자리에서 함부로 못 누른다. 정작 **「지금 표준 태그 27가지가 무엇인지」 보여 주는 길이 없었다.**
   - `mem tags` 는 「할 일을 안 줬다」로 끝나고, `mem tags --check` 는 **표준 밖** 태그만 센다.
   - 결국 `Memory/store/**.md` 의 `tags:` 줄을 세어 많이 쓰인 낱말을 골라 넣었다.
   - 바라는 것 : `mem tags --list`(또는 `--check` 끝에 표준 27가지 나열) 한 줄이면 끝난다.
3. 거절 메시지 두 번째 줄에 `mem add … --new` 가 섞여 나와, 태그 문제가 아니라
   **닮은 기억 덮어쓰기 문제**로 잘못 읽고 `--new` 를 먼저 붙였다가 다시 같은 태그로 거절당했다.
   - 바라는 것 : 관문이 여럿 걸렸을 때 **막은 까닭을 하나씩 줄 나눠** 찍어 주면 좋겠다.
