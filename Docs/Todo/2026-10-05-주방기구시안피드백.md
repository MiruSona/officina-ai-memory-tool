# 주방 기구 시안 작업 mem 피드백 (ProjectMozzi2 · 2026-10-05)

## 잘 된 것

- `mem search 주방 그림` 이 확정 결정(네 단계 · 배치)과 옛 todo 를 맨 위로 올려 줘 배경을 한 번에 잡았다.
- `mem add` 거절 문구가 고칠 것(요약 126자 · 본문 1줄)을 정확히 짚었고 `--check` 로 미리 볼 수 있었다.

## 헷갈린 것

- 첫 `mem add` 가 거절됐을 때 출력 맨 앞에 닮은 기억 id 한 줄만 보이고 거절 까닭은 안 나왔다(「2가지」 라고만). 까닭은 `--check` 를 붙여야 보였다. 거절 때 바로 까닭 줄을 같이 찍어 주면 한 번에 고친다.

## 반복 07 주방 정식 그림 (2026-10-05 · 같은 날 뒷판)

- `mem add` 세 건(caution)이 본문을 파이프로 넘겨 한 번에 들어갔다. `--help` 에 태그 · 범위 목록 보는 법(`mem tags`)이 같이 있어 헤매지 않았다.
- 바람 : `mem tags` 출력이 20줄 넘게 길어 `head` 로 잘랐다. `mem tags --flat`(한 줄 쉼표) 이 있으면 프롬프트에 넣기 좋다.
