## 어긋난 자리에서 배운 것

| 무엇 | 다음에 |
| --- | --- |
| **설계가 문장까지 정한 갈래는 눈금 ×0.7** | 갈래 B③(100 → 70) · 설계(90 → 74) · 뒷정리(320 → 210)가 전부 여기다. **「무엇을 어디에 어떤 조건으로」가 설계에 문장으로 박혀 있으면 구현은 고르는 일이 없어 짧다.** 반대로 「재서 정한다」가 든 갈래(A · B② · C)는 눈금대로거나 넘었다 |
| **계측 갈래는 찬 캐시 첫판을 따로 잡는다** | C1 이 60 → 110 으로 샌 것은 **20k 찬 캐시 첫판 139초**와 스크립트 재실행 2회다. **파생물을 지운 직후 첫판은 2회차의 10배가 될 수 있다.** 계측 소단계에는 **「찬 캐시 첫판 × 실행 횟수」를 눈금에 미리 더한다** |
| **리뷰는 시험·측정 틀을 물려받으면 ×0.3** | 리뷰 A 가 150 → 40 분이 된 것은 **20k 가데이터·사본 다섯 벌·측정 명령줄이 그대로 남아 있어서**다. v0.3 리뷰 A 는 126분이었다. **구현 갈래가 스크래치 저장소를 남기게 시키면 리뷰 눈금을 3분의 1로 잡을 수 있다** |
| **스윕은 재는 자를 먼저 검사한다** | 갈래 A 가 180 → 210 으로 샌 유일한 이유가 **`eval` 이 `search` 와 다른 가중으로 재고 있던 것**이다. 스윕 60점을 다 버리고 다시 돌렸다. **「값을 재서 정한다」 갈래는 첫 30분을 「재는 도구가 진짜 재는 것과 같은가」에 쓴다** |
| **동결이 두 번으로 줄었다** | v0.3 은 네 번이었다. 줄어든 까닭은 **1차 동결 전에 갈래별로 회귀 시험을 다 돌린 것**과 **소유 패키지를 안 겹치게 가른 것**이다. 「동결 → 재측정 → 고침 → 재동결 두 바퀴」 눈금은 **한 바퀴 반**으로 줄여 잡아도 된다 |
| **되돌림도 공수다** | B-04(B08 결정 거절 되돌림)에 26분이 들었다. 코드는 한 줄인데 **시험 두 개를 「재던 뜻을 바꿔」 다시 쓰고 다섯 벌을 재측정**해야 했다. **「채택을 되돌린다」는 결정에는 재측정 시간을 같이 잡는다** |
| **못 미는 것을 증명하는 일도 값이다** | 갈래 A 210분의 산출은 「r@5 가 안 움직였다」이고, C2 연장 70분의 산출은 「짝 캐시는 막다른 길」이다. **둘 다 다음 판이 그 길을 다시 파는 것을 막는다.** 「성과 없음」이 아니라 **닫힌 갈림길**로 적는다 |
