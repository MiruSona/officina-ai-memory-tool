## 이번에 정한 것

| 무엇 | 정한 값 |
| --- | --- |
| **allow 두 꼴을 어떻게 늘리나** | 명령 목록에서 **펼쳐서** 만든다(손으로 22개 나열하지 않는다) — 짝이 빠질 수 없고 `--undo` 도 저절로 맞는다 |
| **`status` allow 범위** | `status:*` 로 넓힌다 — 읽기 전용이라 `--doctor`·`--log` 마다 승인 창이 뜨는 것을 없앤다. 옛 정확 일치는 폐기 목록 |
| **bad 이유를 어디에 남기나** | `Memory/local/bad-reasons/<이름>.err` — 원본 옆이 아니라 `local/` 아래로 모은다 |
| **N2 를 어느 쪽에서 고치나** | 동작이 아니라 **도움말 쪽**을 고쳤다 — 기존 시험이 지금 동작을 의도로 못 박아 둔 것이라, 동작을 바꾸면 시험도 같이 바꿔야 하고 범위가 커진다 |

## 못 한 것 · 남긴 것

- **`mem set` 거절 종료 코드가 `1`.** `add` 는 검사 실패가 `2`고 `mem set` 도움말도 `2` 라고 적혀 있다.
  코드와 도움말이 서로 안 맞는다 — 다음에 맞춘다 (낮음, `cmd/mem/cmd_set.go`).
- `Docs/Guide/훅연동.md` 는 v0.4 에 없다(v0.2·v0.3 에만 있다). allow 22개 설명은 이미 `명령명세.md` 에 넣었으므로
  새로 만들지 않았다 — 진행상황 4-1 의 U1 줄이 `훅연동.md` 를 가리키던 것을 `명령명세.md` 로 고쳐 두었다.
- A7(`set --link` 가 아직 색인 안 된 큐의 `--links` 를 못 봄) · R1(`lint` 20k 자 미달) ·
  R4(증분 530ms) · B-05(규칙 정밀도의 뜻) 는 **이번 뒷정리 범위 밖**이라 안 건드렸다. 진행상황 4-1·4-2 그대로다.
