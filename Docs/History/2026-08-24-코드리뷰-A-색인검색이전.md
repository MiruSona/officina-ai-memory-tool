## 2. R2 — 20k 전/후 실측

**같은 기계 · 같은 씨앗 · 같은 절차로 두 판을 돌렸다.** 다른 것은 exe 뿐이다
(`mem-before.exe` = 리뷰 전 코드, `mem-after.exe` = A1 고친 코드. 둘 다 `CGO_ENABLED=0 go build -trimpath`).

| 무엇 | **전 (before)** | **후 (after)** | 자 |
| --- | --- | --- | --- |
| `index --full` 20k (옛 규격) | 12.68초 · **59,191,296 = 56.45MiB** | 12.64초 · **59,179,008 = 56.44MiB** | ≤ 15초 · ≤ 60MB |
| `migrate --apply` | 24.5초 · 18,804건 큐 | 24.7초 · 18,804건 큐 | — |
| **`migrate` 뒤 첫 `index --full`** | 428.7초 · **62,947,328 = 60.03MiB ✕** | 383.1초 · **61,108,224 = 58.28MiB O** | ≤ 60MB |
| `index --full` (큐가 빈 뒤) | 13.0초 · **61,124,608 = 58.29MiB** | 13.0초 · **61,083,648 = 58.25MiB** | ≤ 60MB |
| 가장 큰 이웃 후보 통 | 15,600 | 15,600 (안 건드림) | — |

**원인을 어떻게 잡았나**

1. `PRAGMA auto_vacuum` = **1(FULL)** · `PRAGMA freelist_count` = **0** — **빈 페이지가 아니다.**
   최종측정이 85% 로 열어 둔 「`VACUUM` 을 안 돌려 확인 못 했다」에 답이 나왔다. `VACUUM` 은 필요 없다.
2. 그러면 남는 것은 **정말로 더 담긴 자료**다. 승격 회차에만 생기는 표는 `inbox_seen` 하나다 —
   `markInbox` 는 승격할 때마다 이름 한 줄을 넣고, `pruneInboxSeen` 은 **30일(`inboxSeenDays`)** 이 지나야 지운다.
   18,804줄 × (이름 + 정수 + 기본키) ≈ **1.7~1.9MB** 로 차이(전 62,947,328 − 후 61,108,224 = 1,839,104바이트 = 1.75MiB)와 아귀가 맞는다.
3. 고침은 **표시를 없애는 것이 아니라 쓸모없어졌을 때 지우는 것**이다 —
   큐 파일이 `archive` 로 가서 `inbox/new` 에 없으면 두 번 승격될 길이 없다.
   **아직 `inbox/new` 에 남은 이름의 표시는 그대로 둔다** (v0.3 리뷰 A #11 · 회귀 시험 `TestPruneKeepsMarkOfWaitingQueue` 통과).

**어느 쪽을 골랐나** — 둘을 저울질했다.

| 길 | 뜻이 얼마나 바뀌나 | 판정 |
| --- | --- | --- |
| ㉠ `note:` 근거를 통째로 안 센다 | 사람이 적은 진짜 note(`note:아트회의2026-08-01` 같은 것)까지 근거에서 빠진다 — **규칙 ②(같은 근거)의 뜻이 바뀐다** | 버림 |
| ㉡ `migrate` 가 자리표시를 `sources` 에 아예 안 넣는다 | `sources-required`(F17)·`sources-note-only`(F18) 판정이 통째로 달라진다 — **lint 오류 건수가 움직인다** | 버림 |
| **㉢ 자리표시 한 값만 근거에서 뺀다** | **바뀌는 것은 `auto_links` 하나뿐**이다. 파생 표라 `index --full` 이 다시 만든다. lint 도 D04(후보 등급)만 덜 운다 | **고름** |

글은 `model.NoteMigrated` 한 자리에 두고 `migrate` 와 `link` 가 같이 본다 —
두 벌로 두면 한쪽만 고쳐져 조용히 다시 뭉친다. **글을 고치면 이미 이전한 저장소가 못 알아보니 고치지 않는다.**

## 5. 못 고친 것 · 안 한 것

- **골든셋 재측정(G1·G2)을 안 돌렸다.** 이번 변경 중 순위에 닿는 것이 하나도 없다 —
  `promote`(승격 표시) · `cmd_index`/`cmd_migrate`(출력 한 줄) · `config`(경고 글) · `link`(자동 이웃 표) · `testdata` 자리뿐이다.
  **자를 옮기지 않았고 검색 코드(`internal/search`·`internal/index` 질의) diff 는 0줄**이다.
  다만 **`auto_links` 가 달라지면 1-hop 가산이 달라질 수 있다** — 자리표시로 잘못 이어지던 짝이 빠지고
  뭉쳐 죽었던 짝이 살아나는 쪽이라 **좋아질 방향**이지만, **골든셋으로 재서 확인한 것은 아니다.**
- `go test -race` 는 안 돌렸다 (뒷정리가 이미 한 판 돌렸고 이번 변경은 새 goroutine 을 안 만든다).
