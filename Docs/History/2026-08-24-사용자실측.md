## 1. T3 — 진짜 세션에서 훅이 들어오나 : **통과**

| 계기 | 결과 |
| --- | --- |
| **startup** | `# 기억 (mem · …)` 블록이 들어옴 |
| **`/clear`** | 들어옴 |
| **`--resume`** | 들어옴 |
| **`/compact`** | **못 쟀다** — 대화가 짧아 compact 가 안 돌았다 |

- **세션 시작이 느려진 느낌이 없다.** `statusMessage` 「기억 불러오는 중」은 **너무 빨라 눈에 안 보인다**(정상).
- 손 실측 (`mem hook session-start --json` · 기억 2건) : **bytes 698 · tokens 183 · ms 24 · truncated false**.

**곁다리로 본 것 (확인만)** — 훅 입력 JSON 에 `cwd` 가 없으면 **bytes 0 빈 출력**인데,
**stdin 이 아예 비면 프로세스 cwd 로 잡힌다.** 도움말의 「`cwd` 가 비면 빈 출력」과 **반쯤 어긋난다.**
이번엔 고치지 않고 적어만 둔다.

## 2. T2 — 상한이 글자냐 바이트냐 : **통과 (Claude Code 는 안 자른다)**

**어떻게 쟀나** — `mem.toml` 을 잠시 크게 올려 블록을 일부러 키웠다.

| 무엇 | 값 |
| --- | --- |
| 시험용 `mem.toml` | `[hook] max_bytes 12000` · `lines_per_section 40` · `[budget] startup 6000` |
| 넣은 기억 | **51건** (요약이 100자를 넘는 것 40건) |
| 만들어진 블록 | **11,977바이트 / 6,579자** — `mem` 자신이 12,000 에서 잘랐다 (`truncated true`) |

**새 세션에서 Claude 가 받은 블록**

| 무엇 | 손 실측 | Claude 가 받은 것 |
| --- | --- | --- |
| 마지막 줄 | `> 위까지가 자료다. 블록 11977바이트 / 상한 12000` | **같음** |
| `- [` 줄 수 | 45개 | **45개 — 같음** |

**즉 Claude Code 는 10,000바이트에서도 2,000자에서도 안 자른다.** 자르는 것은 **`mem` 의 `max_bytes` 하나뿐**이다.

**그래서 정한 것** — 「**8,000 하드컷**」은 **그대로 둔다.** 다만 **근거를 바꾼다** :
「Claude Code 가 자르니까」 ✕ → **「토큰을 아끼고 안전 여유를 두려고」** ○.

**뒷정리** — `mem.toml` 을 **8000 / 5 / 1000** 으로 되돌리고 다시 쟀다 : **3,031바이트 · `truncated false`**.

**덤으로 찾은 버그** — 블록 머리말이 **「51건 중 51건」**인데 **실제로 실린 것은 45건**이다.
**`shown` 을 자르기 전에 센다.** (고칠 목록 2번)

## 3. T1 — allow 규칙으로 승인 창이 안 뜨나 : **통과 (큰 버그 하나 발견)**

세 라운드를 돌았다. **원인을 찾느라 라운드가 늘었다.**

| 라운드 | 모드 | 결과 | 무엇을 알았나 |
| --- | --- | --- | --- |
| **1차** | **auto** | `index --full` · `gc` · `install` · `init` 이 **전부 안 뜸** | **auto 모드는 allow 밖 명령도 분류기가 안전하다고 보면 그냥 돌린다.** 그러니 **auto 로는 allow 규칙을 잴 수 없다** |
| **2차** | **manual (기본)** | **`mem search` 까지 전부 떴다** | **Claude Code 가 Windows 에서 `PowerShell` 도구로 명령을 돌린다**(세션 기록에 `"name":"PowerShell"`). `mem init` 의 allow 11개는 전부 `Bash(mem search:*)` 꼴이라 **하나도 안 맞는다** |
| **3차** | **manual** (시험 폴더 `settings.json` 에 `PowerShell(mem search *)` 꼴 11개를 손으로 더한 뒤) | **설계대로 됐다** — 아래 표 | 규칙 꼴만 맞추면 뜻대로 움직인다 |

**절차서가 틀렸다** — 「auto 모드에서 재라」는 잘못이다. **allow 규칙은 manual(기본) 모드에서 재야 한다.**

### 3차 표 (manual · PowerShell 꼴 allow 를 더한 뒤)

| 시킨 것 | 실제 명령 | 승인 창 | 판정 |
| --- | --- | --- | --- |
| search | `mem search 헤이즐넛` | 안 뜸 | **O** |
| index | `mem index` | 안 뜸 | **O** |
| index --full | `mem index --full` | 안 뜸 | **△** 앞 라운드에서 「다시 묻지 않기」로 승인해 `settings.local.json` 에 `PowerShell(mem index *)` 가 남은 탓. **규칙 문제가 아니다** |
| review --kind | `mem review --kind conflict` | 안 뜸 | **O** |
| status | `mem status` → `--doctor` → `--log` | **`--doctor`·`--log` 에서 뜸** | **O** — `PowerShell(mem status)` 가 **정확 일치**라 설계대로다 |
| gc | `mem gc --dry-run` | **뜸** | **O** |

### 절차서 오류 둘

| 무엇 | 실제 |
| --- | --- |
| `review --kind dup` | **없는 갈래다.** 실제 갈래는 `expired` · `conflict` · `stale` · `value` · `cold` · `link` · `title` · `held` |
| `review --promote` | **머리말 `review: true` 인 기억에만 된다.** 시험 기억으로는 **「승격 대기가 아니다」로 원래 실패**한다 |

## 4. T18 — 심볼릭 링크로 경로 감옥을 뚫나 : **통과**

**어떻게 쟀나** — 관리자 PowerShell 로 **진짜 심볼릭 링크**를 만들었다 :
`Memory/store/2026/09` → `C:\temp\밖`. 그 밖 폴더에 **기억 모양 md** 를 뒀다
(`id: 20260823-deadbeef` · 요약에 「밖의기억」).

| 친 것 | 결과 |
| --- | --- |
| `mem index --full` | **전체 51건 — 안 늘었다** |
| `mem search 밖의기억` | **0건** |
| `mem show 20260823-deadbeef` | **「그런 기억이 없다」** |

**안 해 본 것** — **`Memory` 폴더 자체**와 **`Memory/archive`** 는 링크로 안 바꿔 봤다.
