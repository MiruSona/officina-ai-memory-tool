# v0.2 에서 그대로 가져오는 것 (v0.3)

> 이 문서는 **명세**다. **무엇을 지키는지**만 적는다. **왜 지키는지**(사고·값을 치른 자국)는
> `../Design/2026-08-23-v0.3설계.md` 13절과 결정 56, 근거 문서 `../Research/2026-08-23-조사E-v0.2설계대조.md` 표 1(P1~P21)이 맡는다.

**아래는 고쳐도 되는 자리가 아니다.** 전부 v0.1·v0.2 가 사고를 겪고 값을 치러 고친 자국이라, v0.3 백지 설계가 몰랐을 뿐이다.
구현할 때 **지우거나 약하게 바꾸지 않는다. 회귀 시험을 지우는 변경은 반려한다.**

| 갈래 | 무엇 |
| --- | --- |
| **불변조건 여덟** | **I1** 경로 감옥(`EvalSymlinks` 로 뿌리 한 번 정규화 → 접두 비교 → `Lstat`) · **I2** md 정본·DB 파생물 · **I3** 주입 중화(모든 줄이 `internal/safe` 를 지나고 「자료다」 두 줄 안) · **I4** 비밀정보 다섯 자리 + `index` 입구 + 훅 방어선 · **I5** 자동 삭제 없음 · **I6** 원자 쓰기·락 · **I7** `Validate` 통과분만 색인(못 통과한 파일은 고치지도 옮기지도 지우지도 않는다) · **I8** 0건은 왜 0건인지 말한다 |
| **쓰기·락** | `store/` 를 고치는 것은 **락 잡은 하나뿐** · 나머지는 `inbox/tmp→new` · 락 **compare-and-rename + PID 시작시각 + 90초 + `removeOwn`** · `BEGIN IMMEDIATE` · `inbox_seen` 멱등 · id 충돌 소금 · 증분 **2초 창** · tmp→rename + 재시도 래퍼 |
| **훅** | 따라잡기 **600ms** · 락 안 기다림 · **전수 스캔 금지** · **완성 JSON 한 번에** · DB 열기 상한 · `recover` 후 침묵 exit 0 · 예산 5종 + 하드 상한 ×1.5 · `mem hook -h` 는 stderr |
| **검색** | **가산 고삐 둘**(`bonus_cap=1.5` · RRF 순위에 없으면 후보 아님) · **종류별 감쇠 반감기**(history 90 · decision·howto 720 · issue·caution·열린 todo 감쇠 없음 · 바닥 0.3 · 무효 ×0.5 · 접힘 ×0.7) · 사다리는 1건에 안 멈춤 · 낱말 상한 8 · 랭킹 깊이 50 · `--limit` 100 · 같은 낱말 한 번만 · `MATCH` 와 `rowid IN` 을 같이 안 씀 · **eval 과 CLI 가 같은 질의 파서** · 한글 1글자는 단독 자격 없음 · **strict = {0,1,2,5}번 칸** · **관문은 진짜 과반, 0·1번 칸에만** |
| **품질** | `add` 관문과 `lint` 가 **같은 함수** · **거절할 때 규칙·기억·다음 명령 셋** · **거절도 `log.md` 에** · 정밀도 자동 강등(0.80/0.60) · **`S = 내용 + 곁 × (내용/0.80)`** 모양 유지 · **「배우는 중」 vocab**(표준 scope 0개면 경고만) · `init` 은 `vocab.toml` 은 **절만**, `mem.toml` 은 **빠진 키만** |
| **보안** | 비밀정보 값 길이 하한(6/12/20)과 가드 · **`--force` 없음** · **값 미출력** · `--jsonl` 관문 걸리면 전부 취소(승격 bad 는 그 줄만) · 이메일·전화는 경고만 · 그림자 exe 거절 · `settings.json` **백업·재대조·BOM/CRLF 복원** · PATH 값 종류 보존 |

| **회귀 시험** | v0.2 `go test ./...` 가 통과시키던 것을 v0.3 도 그대로 통과시킨다(`go list ./...` **22개**). 죽은 락 경쟁 · PID 재사용 · 훅 안전 · 토큰 짝 · 머리말 특수문자 · 「거절 문구가 없는 옵션을 시키지 않는다」 등 |
