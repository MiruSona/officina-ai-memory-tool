**v0.3 은 이 표를 안 쓴다**(결정 8 이 폐기). 다음 판이 다시 볼 수 있게 도구와 실측 문서만 남겼다.
`cmd/mem` 이 이것을 import 하지 않는다.

## 2. 의존 방향

**위에서 아래로만 부른다.**

```
cmd/mem
  → hook · gc · lint · review · eval · install
    → quality → search → index → store → model
         ↘ link ↙          ↘ embed ↗
```

`i18n` · `budget` · `token` · `secret` · `simhash` · `safe` 는 **누구나 부를 수 있는 잎 패키지**다.
`link` 도 잎에 가깝다 — DB·파일을 모르고 `Doc` 구조체만 받는다.
`embed` 는 `index` 아래가 아니라 **옆**이다. 벡터는 `index.db` 가 아니라 `Memory/vectors.bin` 에 따로 있다.

## 3. 패키지가 지켜야 할 규칙 넷

| 규칙 | 내용 |
| --- | --- |
| **DB 는 프로세스당 두 번까지만 연다** | `index.Open` 은 `internal/index` 밖에서 못 부른다. `cmd/mem` 이 시작할 때 저장소 하나를 열어 핸들을 아래로 넘긴다. `index.OpenCount()` 를 시험이 센다 |
| **`store/` 를 고쳐 쓰는 것은 `index` 뿐** | 쓰기는 전부 `index` 를 거쳐야 락과 `BEGIN IMMEDIATE` 가 한 곳에 남는다 |
| **같은 규칙을 두 곳에 적지 않는다** | `add` 관문과 `lint` 는 `quality` 의 **같은 검사 함수**를 쓴다. 규칙 이름 상수도 거기 하나뿐이다 |
| **한글 리터럴은 `i18n` 안에만** | 그 밖 어디에도 한글 문자열을 두지 않는다. `i18n` 은 함수가 아니라 **표(map)** 다 |

## 4. Go 컨벤션

| 규칙 | Go 에서 |
| --- | --- |
| SOLID | 순수 로직(`model`·`search`·`quality`·`gc` 판정)에 적용. 파일·DB 를 만지는 곳에 인터페이스를 억지로 안 끼운다 |
| 익명 struct 금지 | 이름 붙여 파일 위로 뺀다. JSON 파싱용도 마찬가지 |
| 깊이 3단계 | `if err != nil { return err }` 로 일찍 빠져나온다 |
| 삼항·`??` 금지 | Go 에 없다. 풀어 쓴다 |
| 주석 최대 2줄 | 왜 그런지만. 언제 누가는 git 이 안다 |
| `gofmt` 무조건 · `go vet` 깨끗 | 커밋 조건 |

## 6. 빌드

```powershell
.uild.ps1                     # bin\mem.exe 만
.uild.ps1 -Install            # 만들고 mem install --apply 까지 (모델·DLL 도)
go build ./... ; go vet ./... ; go test ./...
```

`build.ps1` 이 하는 일은 `go version` 확인 → `CGO_ENABLED=0` 으로 `go build -trimpath -ldflags="-s -w"` 다.

`-trimpath` 를 꼭 붙인다 — 없으면 exe 안에 만든 사람의 집 폴더 경로가 그대로 박힌다.
**UPX 는 안 쓴다** (시작 속도가 더 중요하고 오탐 확률도 는다).

## 7. 시험 종류

| 종류 | 무엇 | 무엇을 지키나 |
| --- | --- | --- |
| 골든 출력 | `search` · `hook --dry-run` · `lint` 의 Markdown | `testdata/` 의 기대 출력과 비교. `-update` 로 갱신 |
| **토큰 짝** | 같은 낱말을 `ForIndex`·`ForQuery` 에 | 색인용 조각 안에 질의용 조각이 **반드시** 들어 있어야 한다 |
| 한글 회귀 | 두 글자 한글 질의 | 정답 전부 적중 · 오답 0 |
| 영문 회귀 | `dotnet-format` · `MyClassName` 같은 것 | 색인 쪼개기가 버티는지 |
| 0건 설명 | 아예 없는 낱말로 검색 | ①~④ 가 다 나오는지, `--json` 이 `[]` 인지 |
| 사다리 종료 | 오답이 1건만 걸리는 질의 | 1건에서 멈추지 않고 limit 을 채우는지. 칸 꼬리표가 붙는지 |
| 가산 고삐 | 관련도 0 인 고정 `decision` 이 있는 상태 | RRF 후보에 없으면 결과에 안 나오는지 |
| **품질 관문** | 규칙(62개)마다 나쁜 예·좋은 예 | 거절·경고 등급이 맞는지. 골든셋으로 정밀도·재현율까지 |
| **규격 판** | v0.1 머리말과 지금 머리말 | 옛 파일이 옛 자로 재어져 색인에 남는지 |
| **DB 열기 횟수** | `hook session-start` 1회 | `index.Open` 이 **2회를 넘으면 실패** |
| 훅 바이트 | 8,000바이트를 넘기는 블록 | 「자료다」 두 줄이 살아남고 가운데만 잘리는지 |
| **훅 안전** | 일부러 DB 를 깨고 `hook session-start` | **stdout 이 완전히 비고 exit 0** |
| 머리말 특수문자 | 요약에 `\` · `"` · `:` · `#` 이 든 기억을 `add` | 승격·색인·검색이 다 되는지 |
| 동시성 | `add` 를 고루틴 여럿으로 | 유실·중복 0 |
| 락 | `index` 를 둘이 동시에 · 죽은 락을 둘이 동시에 치우기 · PID 재사용 | 하나만 돌고 하나만 rename 에 성공하는지 |
| 마이그레이션 | `user_version` 이 미래 값 | DB 를 안 건드리고 종료 코드 2 |
| 설치 | 빈 폴더에 `init` 을 **두 번** | 두 번째가 아무것도 안 바꾸는지. 남의 훅이 남는지 |
| **보안 회귀** | 경로 탈출 id · 중간 폴더 링크 · 승격 비밀정보 · 주입 자르기 · 폭 없는 글자 · 그림자 exe · `settings.json` 경쟁 | 실제로 터졌던 것을 자산으로 남긴다 |
| **분리** | `v0.3/` 만 딴 폴더로 복사해 `go build` · `go test` | 바깥을 가리키는 것 없이 다 도는지 |

## 8. 떼어 낼 조건

이 폴더는 다 만들면 **떼어 내 독립 git 저장소**가 되고, 나중에 스튜디오 저장소에 서브모듈로 다시 모인다.

1. **코드·문서 어디에서도 바깥 폴더를 가리키지 않는다.** 다른 툴을 참고해야 하면 "어느 툴의 어느 결정을 따른다" 고 **글로** 적는다.
2. `testdata/` 는 자기 것만 쓴다. 바깥 문서를 읽지 않는다.
3. 재 본 실험 코드는 `go test ./...` 가 집지 않게 둔다.

모듈 경로 `github.com/mirusona/officina-ai-memory-tool` 은 **분리 뒤에도 안 바꾼다.** 그래야 서브모듈에서 그대로 빌드된다.
