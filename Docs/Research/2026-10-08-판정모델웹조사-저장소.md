# 판정 모델 웹 조사 — 저장소·모델 편 (2026-10-08)

`mem judge` 를 큰 LLM 서버 없이 돌릴 길을 GitHub · Hugging Face 에서 찾았다.
논문·RAG 실무 편은 다른 두 조사가 맡는다. 모델은 내려받지 않았고, 수치는 모델 카드·저장소 원문에서 옮겼다.

## 결론 먼저

1. **한국어로 지지·반대·무관 셋을 바로 내는 「검증된」 기성 판정기는 없다.**
   사실 일관성 판정기(HHEM · MiniCheck · AlignScore · FactCG · LettuceDetect · Granite Guardian · Lynx)는 거의 다 **영어 전용**이고,
   대부분 **지지 / 비지지 둘**만 낸다. 반대와 무관을 가르지 못한다.
2. **가장 싼 길은 SemIf 를 그대로 두고 모델만 작게 바꾸는 것이다.** Qwen3 · Qwen3.5 의 4B 이하, 카카오 Kanana 1.5 2.1B 는
   Apache-2.0 이고 GGUF 가 있어 지금 llama.cpp 로 바로 돈다. 다만 **이 크기의 NLI 정확도 보고는 거의 없다.**
   찾은 유일한 수치는 Qwen3-0.6B(생각 끔)가 LLM-AggreFact 평균 64.93 (영어, 지지/비지지 둘) 정도다.
3. **한국어 NLI 3갈래 분류기 중 새 후보가 하나 있다** — `mmetamong/ko-decision-roberta-large-klue` (klue/roberta-large, 0.3B).
   카드에 KLUE-NLI 검증 999줄 정확도 90.7% 를 적었다. 이틀 전에 올라온 1인 모델이라 **자기 보고 수치**다.
   같은 표에 우리가 접은 Laya 의 한국어판(`2nugu/laya-ko`)이 81.0% 로 나온다.
4. **「반대 쌍 부족」은 공개 한국어 NLI 로 메울 수 있다.** KLUE-NLI(약 2.8만 쌍, 사람이 씀) 와 KorNLI(약 95만 쌍, 기계 번역) 는
   모순 라벨이 따로 있고 둘 다 CC BY-SA 4.0 이라 상용 가능하다(같은 조건으로 공유 의무).
5. **리랭커는 판정기 대용으로는 반쪽이다.** 「관련 있나」만 재서 지지와 반대를 둘 다 높게 준다.
   무관(C) 거르개로는 쓸 만하고, Qwen3-Reranker 는 지시문을 바꿀 수 있어 「지지하나 예/아니오」로 돌리는 실험은 해 볼 만하다.

읽는 법 :
- 무학습 분류 비교에서 **1B 아래는 크게 떨어지고(0.28~0.36), 4B 에서 8B 와 거의 같아진다.** SemIf 를 줄인다면 **4B 가 바닥**이라는 근거다.
- Veritas 는 Qwen3-0.6B 를 판정 자료로 미세학습해 64.93 → 72.30 으로 올렸다. **작은 모델은 미세학습 없이는 약하고, 미세학습하면 0.4B 인코더 판정기 급까지 온다.**
- 3갈래(지지·반대·무관) 한국어 수치는 어디에도 없다. 재 봐야 안다.

### 「서버 없이 CLI 한 번」이 되나

| 길 | 되나 | 비고 |
| --- | --- | --- |
| `llama-cli` 로 첫 토큰 logprob 받기 | **확인 못 함** | 찾은 문서 모두 logprob 은 `llama-server` 의 `/completion` + `n_probs` 로 받는다 |
| `llama-server` 를 판정 때만 자식 프로세스로 잠깐 띄우기 | 된다 | 「큰 서버」가 아니라 같은 PC 의 작은 모델. 모델 적재가 매번 드니 한 번 띄워 여러 쌍을 몰아 묻는다 |
| `llama-embedding --pooling rank` (리랭커) | 된다 (CI 스크립트·커밋 근거) | 입력 한 줄에 「질의 탭 문서」. **서버 없는 진짜 CLI 한 번.** 리랭커·BERT 분류 모델(llama.cpp #13858)용 |
| Go 에서 llama.cpp 를 직접 부르기 | [yzma](https://github.com/hybridgroup/yzma) (CGo 없이, 별 650, Windows·Linux) | llama.cpp 기능 96% 감싼다고 적었다. logits 함수 이름은 README 에서 확인 못 함 |

## 5. 반대 쌍을 메울 공개 데이터셋

| 데이터 | 크기 | 만든 법 | 라벨 | 라이선스 | 쓸모 |
| --- | --- | --- | --- | --- | --- |
| [KLUE-NLI](https://huggingface.co/datasets/klue/klue) | 약 2.8만 쌍 | 한국어로 사람이 직접 씀 | 함의·중립·모순 | CC BY-SA 4.0 | **가장 좋다.** 번역투가 아니다 |
| [KorNLI](https://github.com/kakaobrain/kor-nlu-datasets) | 950,354 쌍 (학습 942,854 · 검증 2,490 · 시험 5,010) | 학습은 SNLI·MNLI 기계 번역, 검증·시험은 XNLI 사람 번역 | 함의·중립·모순 | CC BY-SA 4.0 | 양이 많다. 번역투 |
| [multilingual-NLI-26lang-2mil7](https://huggingface.co/datasets/MoritzLaurer/multilingual-NLI-26lang-2mil7) | 언어당 약 10.5만 | MNLI·ANLI·FEVER-NLI·LingNLI·WANLI 기계 번역 | 3갈래 | 태그 없음. **ANLI 가 CC BY-NC 라 섞인 부분은 상용 주의** | 한국어 몫만 골라 쓸 수 있다 |
| [WANLI](https://huggingface.co/datasets/alisawuffles/WANLI) | 약 10만 | GPT-3 생성 + 사람 검수 | 3갈래 | CC BY 4.0 | 영어. 번역해야 한다 |
| [ANLI](https://huggingface.co/datasets/facebook/anli) | 약 16만 | 사람이 모델을 속이게 씀 | 3갈래 | **CC BY-NC 4.0** | 상용이면 제외 |
| XNLI | — | — | — | — | **한국어가 없다** |

주의 : 공개 NLI 의 「모순」은 「남자가 앉아 있다 ↔ 남자가 서 있다」 같은 그림 설명 문장이 많다.
우리 mem 의 반대는 「값이 3에서 5로 바뀌었다」 「이 결정을 뒤집었다」 꼴이다. **분야가 달라 공개 자료만으로 학습하면 game90 에서 또 미달할 수 있다.**
공개 자료로 먼저 「반대」 감을 익히고, 실물 mem 쌍으로 마무리하는 2단 학습이 맞다(ko-decision 모델이 이 2단 방식이다).

## 무엇을 확인 못 했나

- 표의 정확도는 전부 **모델 카드의 자기 보고**다. 같은 셋에서 서로 견준 것이 아니다.
- 한국어 3갈래를 우리 자에 대 본 공개 수치는 하나도 없다.
- CPU 지연은 HHEM(2k 토큰 1.5초) 말고는 보고가 없다.
- `llama-cli` logprob 출력, yzma logits 함수, `llama-embedding` 의 다라벨 분류 출력은 판에 따라 다르니 `--help` 로 확인해야 한다.
- HyperCLOVA X SEED 라이선스의 상용 조건 원문은 읽지 않았다.
