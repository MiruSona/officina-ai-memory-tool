- **19건** : 높음 1 · 중간 5 · 낮음 13. 고침 15 · 판단 필요 1 · 안 고침 3 (후속 둘 포함).

## 확인한 것 (문제 없음)

- **사다리** (`judge.go` `Support`) : 규칙 → Laya → SemIf. 규칙 글자가 `RulesFinal` 에 있으면 멈춤, 없으면 남겨 두고 다음 단. 마지막 단이 없으면 남은 답에 `Unsure`. 오류는 `settle` 이 `ErrDisabled` 만 「모른다」로 바꾸고 나머지는 그대로 올린다.
- **retain** : `retainRulesFinal = {B}` · 규칙 C 뒤 단이 없으면 「unsure C … unrelated:…」 경고 · 안 걸리고 물을 단 없으면 조용히(2번 고친 뒤 근거마다).
- **`--stage`** : 쉼표 묶음을 사다리 차례로 맞추고 빈 값·모르는 값·`rules,,laya` 는 종료 1. 시험 있음.
- **Laya 응답 검증** : 칸 빠짐 · 0~1 밖 · NaN · 합이 1±0.02 밖 → `bad-answer`. 음수·1 넘음·NaN 시험 셋을 더했다. 모델 이름이 없거나 64자 넘으면 `-` 이고 그때는 기록을 안 남긴다.
- **기록 해시** : `hashOf` 는 칸 사이에 NUL 을 넣고, 판 이름(`rules-v1`·`laya-v2`·`support-v3`)과 프로필이 달라 단끼리 안 섞인다.
- **규칙 숫자** : 쉼표 묶음(11,172) · 쉼표 나열(3,5) · 소수 · 범위 · 날짜 · 낱말에 붙은 숫자 제외가 시험대로 돈다. 바이그램·자카드 0 나누기는 막혀 있다.
- **make2** : train 은 스튜디오 store 만, measure 는 다른 store 만. 비밀 꼴 기억은 읽을 때 뺀다. measure 는 장부 하나라 한 기억을 한 번만 쓴다.
