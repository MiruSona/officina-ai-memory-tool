# 결정 관문(C04) 오탐 조사

> 2026-09-23 · 조사만 했다. 코드는 안 고쳤다.
> 대상 : `internal/quality/gate.go` 의 `decisionGate` · `gateRivals` · `LiveDecisionRivals`

## 결론

- **추천 : `gateSummaryCut` 을 0.025 → 0.04 로 올린다. 태그 조건(`gateTagMin = 2`)은 그대로 둔다.**
  - 오탐이 두 저장소 합쳐 91 → 37 짝으로 준다 (**59% 제거**).
  - 사람이 실제로 `--by` 로 덮은 결정 짝(정답지) 중 지금 관문이 잡는 11짝은 **11짝 다 그대로 잡는다.**
  - 막는 비율(태그 둘 겹치는 짝 중)이 16% → 6~8% 로 내려와 설계 결정 39 의 S05 목표(5~20%) 안에 든다.
- **태그에서 scope 이름·흔한 태그를 빼는 안(b)은 쓰지 않는다.** 진짜 부딪히는 아트 결정도 겹치는 태그가
  `art`+`design` 뿐이라, `art` 를 빼면 정답 짝까지 다 놓친다 (정답지 11 → 5).
- 문턱을 올려 놓치는 짝은 **C05(lint 후보)가 그대로 잡는다** — C05 는 태그 하나만 겹쳐도 후보로 올린다.
  C04 는 「저장을 막는」 자리라 좁게, C05 는 넓게 보는 결정 39 의 나눔과 맞는다.
- 거절문에 **부딪힌 상대의 제목을 찍는 것은 필요하다.** 0.04 로 올려도 막힌 짝의 15~25% 만 진짜라,
  사람이 id 만 보고는 판단을 못 한다. **`--not-rival` 새 옵션은 필요 없다** — `--new` 가 이미 C04 를 지난다
  (`decisionGate` 첫 줄의 `opt.AllowDuplicate`). 거절문에 `--new` 줄이 보이기만 하면 된다.

## 어떻게 쟀나

- 두 저장소의 `Memory/store/**/*.md` 를 읽기만 했다 (Officina 706건 · 게임 저장소 296건).
  살아 있는 `decision` 은 Officina 211건 · 게임 85건.
- 같은 scope 에 태그가 하나라도 겹치는 짝을 다 뽑고, 겹친 태그 수와 `summarySim`(제목+요약 글자 3조각 자카드)을
  쟀다. 계산 코드는 `gate.go`·`text.go` 의 식을 그대로 옮긴 임시 Go 프로그램이다 (저장소 밖).
- 정답 두 벌로 대안을 채점했다.
  - **사람 판정** : 지금 문턱에서 막히는 111짝을 제목·요약으로 가렀다.
    「진짜」= 같은 대상을 두고 다시 정한 짝(덮거나 이어야 함) · 「애매」· 「오탐」.
  - **정답지(덮기 기록)** : `superseded_by` 로 이어진 decision 짝 18개. 사람이 직접 「덮는다」고 한 짝이라 가장 믿을 만하다.

## 대안 비교

정탐 = 사람 판정 「진짜」 12짝 + 정답지 중 지금 관문이 잡는 11짝. 오탐 = 사람 판정 「오탐」 91짝.
「애매」 8짝은 셈에서 뺐다.

- **태그를 좁히는 안(b·c)은 정답지를 절반 넘게 놓친다.** 정답지 짝이 겹치는 태그도 `art`+`design`,
  `minipc`+`benchmark` 처럼 흔한 것뿐이다. 이 저장소들에서 태그는 「같은 자리」를 가르는 힘이 거의 없다.
- **요약 닮음이 그나마 가른다.** 지금 관문이 잡는 정답지 11짝의 닮음은 0.044~0.573 이고, 오탐은 0.025~0.04 에 몰려 있다.
- 0.04 와 0.05 의 차이는 정답지 한 짝(게임 `art`, 0.0444)과 오탐 12짝이다.
  0.05 는 게임 저장소 막는 비율이 4.7% 로 S05 목표 아래로 떨어진다. 그래서 0.04 를 고른다.
- 0.04 에서 놓치는 「진짜」 5짝은 대부분 **같은 결론을 다시 적은 짝**이다 (Officina 가지치기 판 셋 등).
  덮지 않고 두어도 모순은 안 생긴다. 모순인 짝은 게임 `art` 한 짝(`20260921-77bca9ea` ↔ `20260922-f2c98236`, 0.0286)뿐이고,
  이것은 C05 lint 가 잡는다.

## 확인 못 한 것

- **사람 판정은 한 사람(조사자)이 한 번 가렀다.** 「진짜/오탐」 경계는 사람마다 다를 수 있다. 「애매」 8짝은 셈에서 뺐다.
- **문턱 아래 짝은 다 보지 않았다.** 0.025 아래에 숨은 진짜 짝은 정답지(덮기 기록)로만 봤다.
  정답지 18짝 중 7짝은 지금 관문도 못 잡는다 (태그가 하나 이하로 겹치거나 닮음 0.02 미만). 이건 문턱과 상관없는 한계다.
- **실제 `mem add` 로 돌려 보지 않았다.** 식을 옮긴 임시 프로그램으로 쟀다. 별칭 치환(`applyAliases`) 뒤 태그로 재지 않았지만,
  저장된 기억은 이미 치환된 태그라 차이는 없을 것으로 본다.
- 다른 갈래가 거절문을 고치는 중이라, 거절문에 `--new` 줄이 실제로 찍히는지는 이 조사에서 보지 않았다.
- 더 볼 만한 후보 : 요약 닮음을 잴 때 「확정」「정했다」「(사용자 확정)」 같은 흔한 꼬리말을 빼기.
  Officina 오탐의 큰 몫이 이 꼬리말이다. 이번에는 재지 않았다.
